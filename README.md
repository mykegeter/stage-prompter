# Stage Prompter

A puppet-show teleprompter for the Pastor's Pals ministry.

Open it at https://mykegeter.github.io/stage-prompter/ and use Install from the browser menu to add it to your phone or PC.

Your shows, timings and audio stay on your own device. Nothing you load is uploaded to this site.
